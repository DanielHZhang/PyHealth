pyhealth.datasets.NHANESDataset
===============================

NHANES 2003-2006 minute-level physical activity data (`PAXRAW_C
<https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2003/DataFiles/PAXRAW_C.htm>`_,
`PAXRAW_D
<https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2005/DataFiles/PAXRAW_D.htm>`_)
linked to demographics and the `2019 public-use linked mortality files
<https://ftp.cdc.gov/pub/Health_Statistics/NCHS/datalinkage/linked_mortality/>`_.
See :meth:`~pyhealth.datasets.NHANESDataset.prepare` for the local input layout.
